# Coronary Assignment Dataset Bundle

This bundle contains:
1. A complete synthetic 16-bit coronary cine dataset that can be used immediately.
2. Ground-truth synthetic vessel masks.
3. Low-contrast and noisy/motion test cases.
4. Real-dataset source/download instructions for DCA1, ARCADE and CoronaryDominance.

The synthetic data contains no patient information.

Use this bundle with the previously supplied `coronary_assignment_project` code.
